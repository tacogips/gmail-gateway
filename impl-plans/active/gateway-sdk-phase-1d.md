- Catalog/service payload drift: inventory every service-produced key and assert full-catalog, resolver, and mode parity in both directions.
- Async bridge deadlock: execute on an independent context and test sync CLI entry from serial/concurrent contexts.
- Capability widening: validate against `gmailFull`, authorize against only `gmail(mode:)`, and assert denied operations make zero URLProtocol requests.
- Test-oracle coupling: expected authorization, arguments, envelopes, and provider effects live in test-owned fixtures and are not derived from the production catalog or resolver registry.
- Destructive malformed CLI invocation: validate exact positional/flag grammar before file reads, document building, resolver dispatch, or provider access, including operations tested in authorized modes.
- Cancellation ambiguity: model Gmail API effect intent explicitly; preserve definitive post-dispatch results and reserve `MUTATION_OUTCOME_UNKNOWN` for a lost result after irreversible dispatch.
- Secret or local-path exposure: normalize only accepted fields, strip `localPath` recursively, and test environment isolation plus envelope contents.
